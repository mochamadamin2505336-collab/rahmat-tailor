# Audit 007 - Detail Pesanan Admin

Tanggal: 2026-11-22

## Scope

Audit fitur detail pesanan admin pada modal PB-20, khususnya tampilan model atau gambar referensi pesanan online.

## Temuan

1. HIGH - Gambar model pelanggan tidak ditampilkan di modal detail.
   Pelanggaran: R-26, R-38, C-2.
   Bukti: API detail mengembalikan `foto_referensi` di [PesananController.php](/c:/laragon/www/rahmat_tailor/app/Http/Controllers/Admin/PesananController.php), tetapi logika modal di [admin.js](/c:/laragon/www/rahmat_tailor/resources/js/admin.js) tidak membaca atau merender nilainya. Modal detail di [admin.blade.php](/c:/laragon/www/rahmat_tailor/resources/views/admin.blade.php) juga belum memiliki area gambar model.
   Dampak: Admin tidak dapat melihat model yang dikirim pelanggan saat menekan detail pesanan.

2. MEDIUM - Modal detail belum memiliki state kosong dan error untuk gambar model.
   Pelanggaran: R-27.
   Bukti: Untuk pesanan tanpa gambar atau jika URL gambar gagal dimuat, modal belum menyediakan teks kosong atau fallback error. Hanya ukuran dan riwayat status yang memiliki state masing-masing.
   Dampak: Admin mendapatkan area kosong yang tidak informatif atau gambar rusak tanpa penjelasan.

3. MEDIUM - Tombol tutup modal tidak memiliki nama aksesibel.
   Pelanggaran: R-39.
   Bukti: Tombol tutup di [admin.blade.php](/c:/laragon/www/rahmat_tailor/resources/views/admin.blade.php) hanya berisi ikon material dan belum memiliki `aria-label`.
   Dampak: Pembaca layar tidak dapat mengenali fungsi tombol tutup dengan jelas.

4. LOW - Tambahan tampilan gambar perlu ukuran tetap agar modal tidak bergeser saat gambar dimuat.
   Pelanggaran: R-40.
   Bukti: Tampilan gambar model masih belum ada, sehingga rancangan yang akan ditambahkan perlu reservasi rasio atau dimensi agar tidak menggeser isi modal.
   Dampak: Ini adalah persyaratan implementasi agar pencegahan layout shift diperhatikan sejak awal.
