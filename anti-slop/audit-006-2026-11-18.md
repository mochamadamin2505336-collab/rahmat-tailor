# Audit 006

## Temuan

1. **HIGH, R-26 dan R-35: Form pemesanan online belum mengirim data ke database**
   - Form `online-order-form` hanya menangani submit dengan `event.preventDefault()` lalu menampilkan kotak sukses statis di [pemesanan.blade.php](/C:/laragon/www/rahmat_tailor/resources/views/pemesanan.blade.php:53).
   - Sebagian besar input ukuran tidak memiliki atribut `name`, sehingga browser tidak dapat mengirim nilai sebagai payload pemesanan.
   - Tombol submit tampak berhasil tetapi tidak memanggil endpoint `/api/pesanan` yang sudah tersedia dan tidak menyimpan pesanan maupun ukuran.

2. **HIGH, R-24 dan R-26: Halaman pemesanan dapat dibuka tanpa autentikasi**
   - Rute `/pemesanan` pada [web.php](/C:/laragon/www/rahmat_tailor/routes/web.php:7) tidak memakai middleware `auth`.
   - Endpoint penyimpanan sudah memakai `auth` pada [api.php](/C:/laragon/www/rahmat_tailor/routes/api.php:31), tetapi halaman Blade tidak mengarahkan pengguna yang belum masuk ke halaman login terlebih dahulu.
   - Akibatnya, pengguna dapat membuka form dan baru mendapat kegagalan saat mencoba submit, bukan login dahulu.

3. **HIGH, R-24 dan R-26: Halaman admin web belum dilindungi middleware**
   - Rute `/admin/{any?}` pada [web.php](/C:/laragon/www/rahmat_tailor/routes/web.php:15) masih tidak memakai `auth` maupun `admin`.
   - Middleware dan pengecekan peran sudah tersedia di [EnsureAdmin.php](/C:/laragon/www/rahmat_tailor/app/Http/Middleware/EnsureAdmin.php:12), dan endpoint API admin sudah menggunakan `auth, admin`.
   - Rute halaman Blade admin perlu menerapkan middleware yang sama agar akses langsung, bukan hanya akses API, benar-benar dibatasi.

4. **HIGH, R-26 dan R-38: Tombol admin selalu ditampilkan di footer**
   - Tautan panel admin selalu dirender di [footer.blade.php](/C:/laragon/www/rahmat_tailor/resources/views/layouts/footer.blade.php:66), tanpa pemeriksaan `@auth` dan peran admin.
   - Pengguna pelanggan dan pengguna belum login dapat melihat tombol menuju `/admin`, meskipun rute API tetap terlindungi.
   - Tombol perlu dibungkus kondisi Blade yang hanya merendernya untuk pengguna dengan peran admin.

5. **MEDIUM, R-38: Bagian layanan masih ditulis secara statis**
   - Lima kartu layanan dan satu kartu CTA ditulis langsung di [index.blade.php](/C:/laragon/www/rahmat_tailor/resources/views/index.blade.php:125), bukan berasal dari data database.
   - Endpoint publik `/api/layanan` sudah tersedia di [api.php](/C:/laragon/www/rahmat_tailor/routes/api.php:14) dan model [Layanan.php](/C:/laragon/www/rahmat_tailor/app/Models/Layanan.php:8) sudah mendukung data aktif beserta urutan.
   - Tampilan perlu tetap dipertahankan dengan mengganti kartu statis menjadi pengulangan `@foreach` dari koleksi server.

6. **MEDIUM, R-38: Bagian galeri masih menggunakan gambar statis**
   - Enam kartu galeri ditulis langsung di [index.blade.php](/C:/laragon/www/rahmat_tailor/resources/views/index.blade.php:238), bukan dari model [Galeri.php](/C:/laragon/www/rahmat_tailor/app/Models/Galeri.php:8).
   - Endpoint `/api/galeri` sudah tersedia di [api.php](/C:/laragon/www/rahmat_tailor/routes/api.php:15), termasuk filter kategori dan URL berkas publik.
   - Struktur kartu perlu dipertahankan sementara sumber data diganti melalui `@foreach`.

7. **HIGH, R-38: Riwayat ukuran tersimpan di backend tetapi belum terhubung penuh ke form admin**
   - Tabel dan model [Ukuran.php](/C:/laragon/www/rahmat_tailor/app/Models/Ukuran.php:8) sudah mendukung penyimpanan satu ukuran per pesanan beserta hubungan pelanggan.
   - `PemesananController::store()` dan `PesananService::buat()` sudah menyimpan ukuran pada pesanan yang dibuat lewat backend.
   - Form Blade belum mengirim ukuran tersebut, dan halaman admin perlu memastikan tab riwayat membaca data nyata dari endpoint yang sudah ada, bukan data statis.

8. **MEDIUM, R-35: Beberapa form menampilkan sukses palsu atau tidak terhubung ke database**
   - Form pemesanan online menampilkan kode nota statis `RT-8294XJ91` setelah submit.
   - Form pelacakan dan booking juga menggunakan `event.preventDefault()` atau `setTimeout()` untuk meniru proses, dan belum konsisten memakai endpoint database.
   - Temuan ini perlu dipisahkan dari scope pemesanan utama agar status sukses tetap bisa diverifikasi dari respons backend.

9. **MEDIUM, R-27: Negara kosong, memuat, dan galat belum lengkap untuk data layanan dan galeri**
   - Halaman publik saat ini memakai konten statis, sehingga tidak memiliki indikator memuat atau negara kosong yang jelas saat data kosong.
   - Backend sudah memiliki endpoint data dan dapat mengembalikan koleksi kosong.
   - Implementasi `@foreach` perlu menggabungkan `@forelse` agar tidak menampilkan area kosong tanpa penjelasan.

## Bukan Temuan

- Konvensi Laravel, model, migration, middleware admin, dan service pemesanan sudah memiliki fondasi yang sesuai untuk sebagian besar perubahan.
- Penyimpanan ukuran untuk celana, baju, rok, kebaya, dan seragam sudah didukung oleh [AturanUkuran.php](/C:/laragon/www/rahmat_tailor/app/Support/AturanUkuran.php:8) dan migration [2026_11_17_100500_create_ukuran_table.php](/C:/laragon/www/rahmat_tailor/database/migrations/2026_11_17_100500_create_ukuran_table.php:8).
- Endpoint admin sudah memuat detail pesanan beserta relasi `ukuran` pada [PesananController.php](/C:/laragon/www/rahmat_tailor/app/Http/Controllers/Admin/PesananController.php:61).
